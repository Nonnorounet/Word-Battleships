# Word Battleships

A two-team Battleships game for adult English learners. To fire at a cell, a team writes a sentence using that cell's row word and column word; the other team accepts or rejects it on its own device. Every ship is a hidden English word, and hits reveal its letters. The board is in 3D.

Ships as:

- **Web page:** one `index.html` that works offline (GitHub Pages, or embedded in Google Sites)
- **Android app:** an APK built with Capacitor
- **Windows app:** a portable `.exe` built with Electron

Word lists come from a Google Sheet. The full spec is in [HANDOFF.md](HANDOFF.md).
